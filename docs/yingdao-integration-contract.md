# 影刀集成契约文档

## 服务地址

- 请求方法：`POST`
- 服务地址：`http://127.0.0.1:8765/audit`
- 请求头：`X-Audit-Token: <本机密钥>`
- 超时时间：60 秒

影刀调用本机审核服务时，只允许访问 `127.0.0.1` 本地地址。调用方必须保护 `X-Audit-Token`，不得写入可公开共享的脚本、截图、日志或第三方系统。

## 影刀职责

影刀自动化流程负责从页面采集审核所需信息，并根据本机审核服务返回结果执行页面动作。

1. 读取页面字段。
2. 读取 `jl_order_no`。
3. 读取 `channel_order_no`。
4. 读取图片标题。
5. 下载图片到本机临时目录。
6. 调用本地审核服务。
7. 当 `decision=pass` 时，点击通过或批准按钮。
8. 当 `decision=manual` 或 `decision=error` 时，按配置点击下一单，或在当前单暂停等待人工处理。

## 影刀禁止事项

影刀流程必须遵守以下限制：

1. 禁止使用云端 OCR。
2. 禁止上传身份证、订单号、订单图片或其他审核数据到任何第三方服务。
3. 禁止自动驳回订单。
4. 禁止在日志中记录图片 URL。
5. 禁止保存 OCR 原始文本。

```json
  "scene_hint": "手机租赁首审",
  "fields": {
    "name": "张三",
    "product_type": "手机",
    "product_name": "iPhone 15 Pro",
    "brand": "Apple",
    "model": "A3104",
    "sn": "F2LX12345678",
    "imei": "356789012345678",
    "merchant": "示例商户",
    "delivery_method": "快递",
    "address": "上海市浦东新区示例路 100 号"
  },
  "images": [
    {
      "title": "身份证正面",
      "path": "C:\\audit_robot\\temp\\yingdao\\JL202605210001\\id_front.jpg"
    },
    {
      "title": "身份证反面",
      "path": "C:\\audit_robot\\temp\\yingdao\\JL202605210001\\id_back.jpg"
    },
    {
      "title": "商品照片",
      "path": "C:\\audit_robot\\temp\\yingdao\\JL202605210001\\product.jpg"
    }
  ]
}
```

字段说明：

- `jl_order_no`：巨量订单号，必填。
- `channel_order_no`：渠道订单号，必填。
- `scene_hint`：页面或业务场景提示，可用于辅助本机服务选择审核策略。
- `fields`：页面结构化字段。缺失字段可以为空字符串，但字段名应保持稳定。
- `images`：影刀已下载到本机临时目录的图片列表。`title` 为页面图片标题，`path` 为本机文件路径。

## 响应处理

本机审核服务返回 `decision` 后，影刀按以下规则处理。

### decision=pass

影刀应点击页面通过或批准按钮，并记录安全日志：

- `jl_order_no`
- 审核耗时 `elapsed`
- 本机处理路径 `path`

不得记录图片 URL、OCR 原始文本或敏感明文。

### decision=manual

影刀应点击下一单，或按配置停留在当前单等待人工处理，并记录安全日志：

- `jl_order_no`
- `manual_reason`
- 审核耗时 `elapsed`
- 本机处理路径 `path`

### decision=error

第一阶段默认应暂停当前流程，等待人工确认错误原因。若配置明确允许跳过错误单，影刀可以点击下一单，并记录安全日志：

- `jl_order_no`
- 错误原因或错误阶段
- 审核耗时 `elapsed`
- 本机处理路径 `path`

## 超时规则

本机审核服务的请求超时时间为 60 秒。若服务在 60 秒内无法完成审核，应返回 `decision=manual`，并给出可记录的 `manual_reason`。影刀不应继续等待该请求，也不应重复提交导致同一订单被并发审核。

## 数据安全要求

1. 审核服务仅在本机 `127.0.0.1` 暴露，不对局域网或公网开放。
2. `X-Audit-Token` 为本机密钥，必须由本机安全配置提供，不得硬编码到可外传材料中。
3. 影刀下载的临时图片应在服务调用完成后删除；如需批量处理，可在每批结束后统一删除。
4. 日志必须安全，只记录排障所需的订单号、决策、原因、耗时和本机处理路径。
5. 日志不得包含图片 URL、OCR 原始文本、身份证图片内容、完整地址截图或其他不必要的敏感信息。
