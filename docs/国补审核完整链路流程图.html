品类与家电地址

品类来源顺序

  1. category_name。
  2. cate_code_name。
  3. 去掉代码前缀后的 product_type。
  4. 商品名/型号与兼容分类器回退。

家电包括冰箱、冷柜、电视、空调、热水器、热水炉、壁挂炉、洗衣机、烘干机等；电脑独立识别；手机、平板、手表、手环、智能眼镜归普通 3C；其余为未知并转人工。

家电地址可通过

包含“商贸”“京东家电”“楼”；包含“村”；末尾数字；末尾数字或中文数字加“组”；数字-数字；市场/商场/建材/店铺等加详细编号；或含号、栋、幢、单元、室、户、门牌、店铺、门店、商铺、B1-、B-。

长度不足 6 且未命中任何明确规则，或只有粗粒度地点时，输出“家电地址粒度不足”。

SN 精确裁决

flowchart TD A["模型候选"] --> B{"可读且明确绑定SN/Serial标签?"} B -->|"否"| DROP["丢弃"] B -->|"是"| C{"是IMEI/EID字段、标签或订单IMEI值?"} C -->|"是"| DROP C -->|"否"| K["可信SN候选"] K --> P["来源优先：设备屏幕 > 机身 > 包装/条码"] P --> Q{"存在两个不同可信读数?"} Q -->|"是"| M["SN不一致 SN_MISMATCH"] Q -->|"否"| R{"存在唯一可信读数?"} R -->|"否"| N["SN未找到 SN_NOT_FOUND"] R -->|"是"| S{"规范化后逐字符等于系统SN?"} S -->|"是"| PASS["SN通过"] S -->|"否"| M
  • 设备屏幕上的可信冲突 SN 权重高于包装，包装一致不能覆盖屏幕不一致。
  • IMEI 可以用于手机/平板激活形式，但永远不能替代系统 SN 精确比较。
  • 相似字符插件只改善读字；_system_sn_supported_by_visual_ambiguity() 固定返回 false。
  • O/0、I/1、S/5、B/8 等差异仍属于不一致，不能自动放行。
