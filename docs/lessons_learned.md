# Lessons Learned

本文件记录项目执行过程中已经解决的问题、原因和后续规避方式。后续任务开始前必须先读取本文件。

## 2026-07-30 分宪法必须落盘

问题：分宪法只在总负责人会话中定稿但未写入文件时，分支 Agent 只能读到 `AGENTS.md`，会回执 `MISSING_SUB_CONSTITUTION`，无法按模块边界执行。

规避：凡要求分支读取的规则，必须写入独立文件，并在 `AGENTS.md` 标明路径。分支只读取总宪法和自己的分宪法，不读取其他模块分宪法。

## 2026-07-30 跨会话工具调用回执

问题：给分支发送任务后，应使用线程工具读取回执；无关 MCP 资源读取不到 Codex 任务状态，容易浪费步骤。

规避：跨会话协调使用 `send_message_to_thread`、`wait_threads`、`read_thread`。工具调用类踩坑只要会影响后续项目协作、测试或验收，就记录到本文件；一次性、无复用价值的小失误不必记录。

## 2026-07-30 分支回执必须进入总负责人汇报队列

问题：分支任务完成并返回回执后，如果总负责人没有立即读取并汇报，会造成用户看不到已完成成果，违反“任一分支任务完成后立即按三项格式汇报”的要求。

规避：每次派发分支任务后，必须把该分支加入待回执队列。总负责人在派发新任务、回复用户或结束当前轮次前，必须先用 `wait_threads` 或 `read_thread` 检查待回执队列；发现完成回执后立即验收并按三项格式汇报。不得因为切换到其他任务而漏报已完成回执。
