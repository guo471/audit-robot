# SN 检测分宪法

## 1. 目标
SN 阶段只负责一件事：从激活/SN 图片组读取可信 SN，并与系统 SN 做精确比对。

在不违背总宪法“不误放”原则下，尽量降低误转人工、模型成本和相似字符幻觉。

## 2. 边界
SN 阶段只处理 SN 读取与比对，不处理采集、地址、商品合规、图片真实性、报告和页面回写。

SN 通过后才能进入后续合规阶段。SN 不通过、看不清、不确定或结构异常时，转人工。

## 3. 严格比对
可信 SN 必须与系统 SN 规范化后逐字符完全一致，才可通过。屏幕 SN 优先；包装 SN 只能辅助，不得覆盖冲突的屏幕 SN。

未读取到完整可信 SN，输出 `SN_NOT_FOUND`。读取到可信但不一致的 SN，输出 `SN_MISMATCH`。

## 4. 提示词规则
SN 提示词必须精简，正文永远控制在 500 字以内。

禁止通过不断堆砌提示词优化 SN。每次新增提示词要求时，必须先删除同等或更多旧冗余内容。

提示词只允许描述 SN 读取任务，不得夹带合规、真实性、地址、采集或报告规则。

## 5. 插件规则
SN 字符插件只能帮助模型看清相似字符，不能改变最终精确比对规则。

任何插件默认不得直接扩大自动通过范围。插件改动必须先 shadow 验证，证明不增加误放风险后，才可考虑 enforce。

## 6. 验收
- 可信冲突 SN 继续转人工
- 相似字符不自动通过
- 未读到完整可信 SN 继续转人工
- SN 通过后非 SN 阶段结果不被改动
- 提示词不超过 500 字
