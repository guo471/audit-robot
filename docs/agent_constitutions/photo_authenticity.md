# 图片真实性插件分宪法

## 1. 职责
插件只负责判断图片是否存在二次翻拍、明显非实拍等真实性风险。

## 2. 边界
插件不介入采集、预检、SN比对、合规主结论、报告生成、页面回写。

## 3. 规则
- 只看可见证据，不看水印、文件名、路径、尺寸、EXIF、品牌记忆
- 明显外部载体、相册界面、画中图完整边界、异常跨域摩尔纹，才记风险
- 商品自身屏幕内的正常UI、反光、局部摩尔纹，不直接等于风险
- 证据不足时只记不确定，不硬判假
- 不得因单一弱证据扩大到整图假设

## 4. 模式
- `off`：完全不启用
- `shadow`：只输出观察，不改最终结果
- `enforce`：允许把插件结果接入最终裁决

## 5. 接入原则
插件结果不得推翻已稳定的主链结论，除非处于 `enforce` 且证据明确。
插件不得把“看起来像”升级成“必然造假”。

## 6. 验收
- 关闭插件时主链结果不变
- `shadow` 下只记录不裁决
- `enforce` 下不扩大误杀
- 真实性规则不外溢到合规主规则
