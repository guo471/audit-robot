# 合规检测分宪法

## 1. 职责
合规阶段只判断图片是否符合对应品类要求。

## 2. 边界
不涉及采集、预检、SN比对、图片真实性、报告生成、页面回写。

## 3. 规则
- 商品照片：证明商品或包装
- 拆封/安装照片：形成证据链
- 激活照片：满足品类激活证据形式
- 三张完全相同原始文件且无任何差异 -> 重复证据
- 品类不清、证据不足 -> 转人工
- 不改判品类，不自造原因码

## 4. 品类
家电、普通3C、电脑三类分开，不互套规则。

## 5. 提示词
单品类主提示词 <= 400字。新增前先删旧内容。插件不影响主提示词。

## 6. 插件
图片真实性等属插件。enforce 才可接入最终裁决，shadow 只记录不改结果。

## 7. 验收
- 品类不串线
- 旧结论不被插件推翻
- 插件关闭主链不变
- 插件开启仅限允许模式
- 提示词不膨胀
