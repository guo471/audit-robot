完成首次读取后，仅对 SN 候选中的易混字符位置回看原图并逐字符复读。判断必须以原图实际可见的笔画结构为准，并优先使用同一标签或同一屏幕中清晰的同字体字符作为参照。

以下内容是字形观察判据，不是字符等价表，也不是自动替换表：

1. V / Y
- V：两条斜线在底部交汇，没有向下延伸的竖线。
- Y：上部左右分叉，交汇后还有一条向下延伸的笔画。

2. 0 / O / Q
- 0：轮廓近似纵向椭圆，比同字体 O 更窄；若该差异不可见则保持不确定。
- O：轮廓更接近圆形，整体比 0 更圆润。
- Q：圆形或椭圆形轮廓的右下方带有一条短斜线或尾笔。
- 判断时以原图实际笔画为准，并结合相同标签或屏幕中的同字体字符确认。

3. 8 / B
- 8：上下两个闭合轮廓连接，左侧通常没有贯穿上下的独立竖直主干。
- B：左侧有明显竖直主干，右侧连接上下两个弧形轮廓。

4. 5 / S
- 5：顶部通常有横线，并由折线或转角连接下部弧线。
- S：整体为连续曲线，顶部没有独立横线。

5. 2 / Z
- 2：上部通常是曲线或弧形转折，底部为横线。
- Z：顶部和底部为两条横线，中间由直斜线连接。

6. 6 / G
- 6：下部有闭合环，上部笔画向上延伸或回钩。
- G：主体接近未完全闭合的圆，开口附近通常有向内或向右的短横笔。

7. 1 / I / L
- 1：以单条竖直主笔为主，顶部可能有短斜笔。
- I：竖直主笔上下可能同时带有水平衬线。
- L：竖直主笔与底部水平笔形成直角。

8. J / U / L
- J：竖直主笔底部向左弯曲，通常没有左侧完整竖线。
- U：左右两条竖线由底部弧线连接。
- L：竖直主笔与底部水平直线连接，没有弧形底部。

9. W / V / N
- W：由连续的下折和上折笔画组成，可看作两个相连的 V。
- V：只有一次向下交汇和向上分开的结构。
- N：左右两条竖直主笔由中间斜线连接。
